This book describes the architecture of the Evolved Packet Core (EPC) and
the signaling procedures that run between its network elements. Each
procedure has a call flow diagram and a step-by-step description of its
messages, and each technical claim cites the 3GPP Technical Specification
(TS) and clause that defines it, so that a network engineer can move
directly between this book and the specifications.
