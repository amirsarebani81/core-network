This book describes the architecture of two generations of the mobile
packet core network, and the signaling procedures that run between their
network elements. Part I covers the General Packet Radio Service (GPRS)
core network, and Part II covers the Evolved Packet Core (EPC). Each
procedure has a call flow diagram and a step-by-step description of its
messages, and each technical claim cites the 3GPP Technical Specification
(TS) and clause that defines it, so that a network engineer can move
directly between this book and the specifications.

= Part I: GPRS Core

[partintro]
This part describes the General Packet Radio Service (GPRS) core
network: its network elements and the interfaces between them, the
GTPv1-C protocol that carries signaling between the GPRS Support Nodes,
and the PDP context activation procedure.

= Part II: Evolved Packet Core (EPC)

[partintro]
This part describes the Evolved Packet Core (EPC) with Control and User
Plane Separation (CUPS): its network elements and interfaces, the
protocols that carry signaling between them, the procedures for attach,
detach, service request, and bearer management, and the use of RADIUS on
the SGi interface.
