This book describes the architecture of the mobile packet core network
and the signaling procedures that run between its network elements. Each
generation of the packet core has a part of its own, and a further part
describes the policy and charging control framework that operates across
these generations. Each procedure has a call flow diagram and a
step-by-step description of its messages, and each technical claim cites
the 3GPP Technical Specification (TS) and clause that defines it, so that
a network engineer can move directly between this book and the
specifications.
