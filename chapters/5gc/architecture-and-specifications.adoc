== Architecture and Specifications

The 5G Core Network (5GC) is the core network of the 5G System (5GS).
This chapter shows the 5GC in the non-roaming reference point
representation that TS 23.501 clause 4.2.3 defines, with the Charging
Function (CHF) added on the N40 reference point, which the 5G data
connectivity charging architecture defines (TS 32.255 clause 4.2).
